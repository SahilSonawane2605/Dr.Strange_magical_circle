# 🪄 Doctor Strange Magical Circle

> "The language of the mystic arts is as old as civilization itself."

An interactive Computer Vision project inspired by Doctor Strange's iconic magical shields from the Marvel Cinematic Universe.

Using real-time hand tracking powered by MediaPipe and OpenCV, this project detects hand gestures through a webcam and generates rotating magical circles that appear around the user's hand, creating a cinematic Doctor Strange-inspired experience.

---

## 🎥 Demo

Raise your hand in front of the camera and perform the gesture.

✨ The mystical shield appears.
🔄 The magical circles rotate in opposite directions.
🪄 Become the Sorcerer Supreme.

---

## ✨ Features

🖐️ Real-Time Hand Tracking

* Detects hand landmarks using MediaPipe
* Tracks finger positions and hand movements
* Runs directly through a webcam

🪄 Doctor Strange Magic Shield

* Animated magical circles
* Dual rotating shield effect
* Real-time positioning on the user's hand

⚡ Dynamic Gesture Detection

* Calculates hand ratios and distances
* Activates magic effect based on hand posture
* Interactive visual experience

🎬 Cinematic Experience

* Inspired by Marvel's Doctor Strange
* Smooth visual overlays
* Real-time animation effects

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/SahilSonawane2605/Dr.Strange_magical_circle.git
```

Navigate to the project folder:

```bash
cd "Doctor Strange Filter"
```

Install dependencies:

```bash
pip install opencv-python mediapipe numpy
```

Run the project:

```bash
python main.py
```

## 🎯 How It Works

1️⃣ Webcam captures live video.

2️⃣ MediaPipe detects hand landmarks.

3️⃣ Finger positions and hand geometry are analyzed.

4️⃣ When the gesture condition is met, the magical shield activates.

5️⃣ Two Doctor Strange magic circles rotate in opposite directions to create the mystical effect.
